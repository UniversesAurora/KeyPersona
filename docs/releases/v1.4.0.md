Windows Terminal 和 Terminal Preview 现在可以分别设置和记住输入法。普通程序也可以从托盘按安装位置区分，方便同时使用两个同名 EXE。

## 下载与升级

- `KeyPersona.exe` 可直接运行，适用于 64 位 Windows 10 和 Windows 11。
- `KeyPersona-1.4.0-windows-x64.zip` 还包含配置示例、README、更新日志和许可证。
- `SHA256SUMS.txt` 可用于校验 EXE 和 ZIP。

升级时先退出旧版，替换程序目录里的 `KeyPersona.exe`，保留 `config.ini`、`state.ini` 和 `state.ini.bak`。同名程序原有的共享规则可以继续继承。按包或安装位置单独识别的应用会各自学习，旧的共享记忆仍保留在原处。

## 本版变化

- 「当前应用输入法设置」可独立控制自动切换和自动记忆。普通程序可勾选「为此安装位置单独保存」。若程序搬了目录，在 `config.ini` 更新该应用身份对应的路径即可沿用设置和记忆。
- 托盘可设置始终以管理员身份运行。开启开机自启动时，使用当前用户的登录计划任务。
- 新增「清除失效记忆」和「清除失效配置」。清理前可查看具体条目。Windows 应用包卸载和程序搬家产生的记录由用户手动清理，输入法失效仍在复查后自动处理。
- 输入法菜单改回单列，按语言加分隔线。关闭自动切换后，中文符号转换仍可单独使用。
- 修复 Terminal 等应用窗口还未显示时漏掉输入法恢复的问题。程序会等待窗口显示和输入控件就绪，再核对是否需要切换。

## 验证与适用范围

通过源码自检、编译后自检和隔离启动测试。在 Windows 11 上核对了两版 Terminal 的独立规则和输入法恢复，也用两个同名 EXE 验证了路径隔离、关闭后恢复共享及重新启用。失效条目的预览、取消和分别保存使用隔离数据验证。

程序目录需要允许当前用户写入。输入法内部模式能否恢复取决于输入法和当前输入控件。清理检查依据明确的失效目标，配置语法和拼写需手动检查。
