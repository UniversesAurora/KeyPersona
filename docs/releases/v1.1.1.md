KeyPersona 1.1.1 修复自动记忆把状态记到错误窗口，以及清除记忆后立即重新生成记忆的问题。

## 下载

- `KeyPersona-1.1.1-windows-x64.zip`：包含 EXE、默认配置示例、README、CHANGELOG 和 MIT License。
- `KeyPersona.exe`：单文件程序，适合直接替换现有 EXE。
- `SHA256SUMS.txt`：EXE 和 ZIP 的 SHA-256。

## 修复后台窗口错误学习

窗口切换完成后，KeyPersona 不再重新读取已经失去前台的旧窗口。输入法采样现在只接受仍与当前前台顶层 HWND 一致的窗口。

这可以避免以下情况：

- Raycast 中手动切换到英文后，关闭搜索框时又被错误记回中文。
- 新窗口的 TSF active profile 被写入上一个窗口。
- 后台线程的默认 IME window 状态被误认为输入框退出前的状态。

## 清除记忆后不再立即重新学习

清除当前或全部自动记忆后，当前输入法只作为未持久化的观察基线：

- 匹配用户规则时显示用户规则来源。
- 匹配全局默认时显示全局默认来源。
- 其他状态显示“当前状态（未记忆）”。
- 观察基线不会写入 `state.ini`，也不会在下次进入窗口时覆盖规则。
- 只有之后发生的稳定状态变化才会成为新的自动记忆。

## 升级

退出旧版后替换 `KeyPersona.exe` 即可。现有 `config.ini`、`state.ini` 和用户规则可以继续使用，不需要迁移配置。

ZIP 中的 `config.example.ini` 仅供新安装参考，不要用它覆盖自己的 `config.ini`。

## 已知限制

- 仅支持 64 位 Windows 10 和 Windows 11。
- 程序目录必须允许当前用户写入。
- 已验证英语（美国）和微信输入法 2.1.4.6；其他 TSF 输入法会自动发现，但内部模式读写取决于其 IMM 支持。
- 普通权限进程可能无法控制管理员权限窗口的输入法。
- 发布文件没有数字签名，Windows SmartScreen 或安全软件可能提示风险。
