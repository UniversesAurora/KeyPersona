修复 Windows 登录后后台进程已经运行、托盘图标却没有出现的问题。管理员自启动可能与 Windows 任务栏同时初始化，首次注册图标失败时，现在会短期重试。Windows 重建任务栏时，也会检查并恢复图标。

## 下载与升级

- `KeyPersona.exe` 可直接运行，适用于 64 位 Windows 10 和 Windows 11。
- `KeyPersona-1.4.1-windows-x64.zip` 包含 EXE、配置示例、README、更新日志和许可证。
- `SHA256SUMS.txt` 可用于校验 EXE 和 ZIP。

升级时先退出 KeyPersona，再替换程序目录里的 `KeyPersona.exe`，保留同目录的配置和记忆文件。
