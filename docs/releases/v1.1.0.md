KeyPersona 1.1.0 调整了用户规则与自动记忆的关系。应用规则和当前窗口规则现在只提供没有记忆时的默认输入法，不再持续锁定窗口。

## 下载

- `KeyPersona-1.1.0-windows-x64.zip`：包含 EXE、默认配置示例、README、CHANGELOG 和 MIT License。
- `KeyPersona.exe`：单文件程序，适合直接替换现有 EXE。
- `SHA256SUMS.txt`：EXE 和 ZIP 的 SHA-256。

## 规则不再阻止手动切换

- 自动记忆开启时，KeyPersona 依次使用会话记忆、持久记忆、用户规则和全局默认。
- 用户规则只在窗口没有记忆时提供初始输入法。
- 进入窗口后手动切换输入法不会再被规则改回；稳定后的状态会成为该窗口的新记忆。
- Windows Terminal 的英语规则仍可作为初始默认值，但用户可以随时切换到中文。

## 自动记忆开关

托盘菜单新增“自动记忆输入法”：

- 开启：学习并恢复每个窗口最后使用的输入法。
- 关闭：不读取或写入自动记忆，只在进入窗口时执行匹配的用户规则。
- 关闭时没有规则的窗口保持原状，用户在窗口内仍可自由切换输入法。

## 清除记忆

- “清除当前窗口的自动记忆”只重置当前窗口。
- “清除所有自动记忆…”会清空会话记忆、`state.ini` 和 `state.ini.bak`。
- 两个操作都保留 `config.ini` 中的命名输入法、用户规则和全局默认设置。

## 升级

退出旧版后替换 `KeyPersona.exe` 即可。保留原有 `config.ini`、`state.ini` 和 `state.ini.bak`；不要用 ZIP 中的 `config.example.ini` 覆盖自己的配置。

旧配置没有 `autoMemory` 时默认开启，不需要手动迁移。通过托盘设置新的当前窗口默认输入法时，程序会清除该窗口的旧自动记忆，让新默认值立即生效。

## 已知限制

- 仅支持 64 位 Windows 10 和 Windows 11。
- 程序目录必须允许当前用户写入。
- 已验证英语（美国）和微信输入法 2.1.4.6；其他 TSF 输入法会自动发现，但内部模式读写取决于其 IMM 支持。
- 普通权限进程可能无法控制管理员权限窗口的输入法。
- 发布文件没有数字签名，Windows SmartScreen 或安全软件可能提示风险。
