KeyPersona 1.0.0 是首个正式开源版本。

## 下载

- `KeyPersona-1.0.0-windows-x64.zip`：包含 EXE、默认配置示例、README、CHANGELOG 和 MIT License。
- `KeyPersona.exe`：单文件程序，首次运行会在同一目录创建配置和状态文件。
- `SHA256SUMS.txt`：两个发布文件的 SHA-256。

## 功能

- 按窗口记忆并恢复输入语言和可读写的输入法中英文模式。
- 支持全局默认、应用用户规则和当前窗口用户规则。
- 自动学习 Win+Space、语言栏及输入法内部切换后的状态。
- 自动发现新增输入法，并把可选状态写入运行时 `config.ini`。
- 清理重复或已经不可用的输入法状态、规则和学习记录。
- 前台切换后先等待 Windows 自己恢复输入法，仅在状态不符时补偿切换。
- 托盘菜单支持左右键打开、开机自启动、状态查看、配置与记录管理。
- 可选修正中文模式下反引号键输出，不影响 Ctrl、Alt、Win、Shift 组合键。

## 从 IME Memory 升级

1. 退出旧程序。
2. 保留原有 `config.ini`、`state.ini` 和 `state.ini.bak`。
3. 把 `KeyPersona.exe` 放到原程序目录，或把这些文件一起复制到新的可写目录。
4. 运行 `KeyPersona.exe`。

程序会迁移旧日志、自启动快捷方式和 Run 注册项。ZIP 中的 `config.example.ini` 仅供参考，不要覆盖已有 `config.ini`。

## 已知限制

- 仅支持 64 位 Windows 10 和 Windows 11。
- 程序目录必须允许当前用户写入。
- 已验证英语（美国）和微信输入法 2.1.4.6；其他 TSF 输入法会自动发现，但内部模式读写取决于其 IMM 支持。
- 普通权限进程可能无法控制管理员权限窗口的输入法。
- 发布文件没有数字签名，Windows SmartScreen 或安全软件可能提示风险。
