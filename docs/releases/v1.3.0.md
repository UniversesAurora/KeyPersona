KeyPersona 1.3.0 改进了输入法识别和窗口切换。托盘菜单现在按语言分栏，也可以为单个应用关闭自动记忆或开启强制保持。

## 下载与升级

- `KeyPersona.exe` 可直接运行，无需安装 AutoHotkey。
- `KeyPersona-1.3.0-windows-x64.zip` 包含 EXE、配置示例、README、更新日志和许可证。
- `SHA256SUMS.txt` 可用于校验 EXE 和 ZIP。

升级时先退出旧版，再替换 `KeyPersona.exe`。保留程序目录里的 `config.ini` 和 `state.ini`，继续使用现有设置和记忆。

## 本版变化

- 「全局默认输入法」和「当前窗口默认输入法」按语言分栏。普通键盘直接选，输入法的中文、英文等模式可展开选择。如果只想切换输入法，可以选「仅切换输入法」。
- 输入法名和语言名取自 Windows。例如，日语栏显示系统登记的「微软输入法」。旧式键盘布局注册的 IME 也会被纳入发现。
- 「当前应用输入法设置」新增两个开关。「关闭此应用的自动记忆」让该应用只使用匹配的用户规则。「强制保持目标输入法」会在检测到输入状态偏离后恢复目标。两项默认关闭。
- 改进弹出式窗口的恢复时机。程序会等实际输入控件获得焦点，确认输入源后再检查内部模式。
- 「记忆管理」收录打开状态文件和清除记忆。「关于」窗口可打开项目仓库和作者主页。

## 验证与限制

通过源码自检、编译后自检和隔离启动测试。自动测试覆盖焦点变化、输入法识别、同名输入法分栏、勾选状态和按应用的输入法策略。本机启用的微信输入法和美式键盘已通过 Windows 枚举核对。微软日语输入法和万能五笔的实际模式切换仍待实测。

适用于 64 位 Windows 10/11。程序目录需允许当前用户写入。输入法内部模式是否可恢复取决于输入法和当前输入框。
