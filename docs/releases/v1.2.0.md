KeyPersona 1.2.0 新增中文符号转英文和成对符号补齐，两项功能均可按应用分别设置。

## 下载

- `KeyPersona-1.2.0-windows-x64.zip`：包含 EXE、配置示例、README、CHANGELOG 和 MIT License。
- `KeyPersona.exe`：单文件程序，可直接替换现有 EXE，无需安装 AutoHotkey。
- `SHA256SUMS.txt`：EXE 和 ZIP 的 SHA-256。

## 中文符号转英文

托盘菜单新增“中文符号转英文”，按常用标点、括号与引号、其他符号分组，支持逐项开启。转换覆盖美式键盘的 32 个符号按键，包括 `￥ → $`、`…… → ^`、`—— → _`、`、 → \`、`。 → .` 和 `《》 → <>`。

转换只在中文输入模式下生效，输出按键在美式键盘上对应的符号。Ctrl、Alt、Win 组合键保留原有行为，不修改粘贴内容或已经写好的文本。

## 自动补齐

- 圆括号、方括号、花括号、尖括号、单引号、双引号和反引号可分别开启补齐。
- 输入左括号时插入一对符号，并把光标放在中间；输入右括号只输出右括号。
- 引号和反引号每次按下都会插入一对。

## 按应用设置

“当前应用符号设置”包含转换总开关、逐项符号转换和自动补齐，每项可选“跟随全局 / 开启 / 关闭”。同一 exe 的所有窗口共用设置。

可以全局关闭，只在某个应用开启转换；也可以全局转换某个符号，在指定应用关闭它。转换和补齐分别保存，修改其中一项不会重置另一项。“全部跟随全局”会清除该应用的所有符号覆盖设置。

所有转换和补齐选项默认关闭，由用户自行开启；已有明确保存的设置会保留。补齐生效时，该应用最终采用的转换总开关和对应符号转换也必须开启。

## 修复

设置当前窗口默认输入法后，托盘菜单关闭、目标窗口重新成为前台时立即切换。等待期间不抢焦点；如果用户已切到其他应用，等目标窗口下次获得前台时应用。

## 升级

退出旧版并替换 `KeyPersona.exe`，保留原有 `config.ini` 和 `state.ini`。ZIP 中的 `config.example.ini` 仅供参考，不要覆盖个人配置。

存在旧 `backtickInChinese` 配置时，程序会迁移到 `[punctuation]` 并删除旧键，原来已经开启的反引号转换会保留。已有新设置优先，没有旧配置则不迁移。应用符号设置保存在 `[punctuation-app.<名称>]`。

## 验证与限制

本版通过源码自检、编译后自检和隔离烟雾测试。新增自检覆盖 32 个符号按键的映射、成对输出和光标移动指令、配置保存、应用覆盖优先级及旧配置迁移。

支持 64 位 Windows 10/11，程序目录需允许当前用户写入。符号转换按美式键盘物理键位处理；输入法内部模式读写取决于其 IMM 支持。编辑器自带补齐时，可以关闭该应用的 KeyPersona 补齐。普通权限进程可能无法控制管理员权限窗口。发布文件未签名。
